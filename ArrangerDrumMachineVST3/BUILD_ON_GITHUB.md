# Atalho: compilar na nuvem

O arquivo `.github/workflows/build-vst3.yml` deste projeto automatiza a compilação no GitHub Actions.

- Envie o conteúdo desta pasta para um repositório GitHub, preservando `.github/workflows/build-vst3.yml`.
- Faça commit.
- Abra **Actions**, aguarde o workflow ficar verde e baixe o Artifact `Arranger-Drum-Machine-VST3-Windows-x64`.
- Extraia `Arranger Drum Machine.vst3` e copie a pasta para `C:\Program Files\Common Files\VST3\`.

Instruções completas no `README.md`.
